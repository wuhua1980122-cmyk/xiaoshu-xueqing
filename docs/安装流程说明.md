# 学情课堂工具包 — 完整安装与使用流程

> 给接收方的操作手册，从零基础到开课，共 5 步。

---

## 第一步：安装 Node.js（只需一次）

教室电脑上如果没有 Node.js，先装。两种方式选一个：

### 方式 A：安装版（推荐，最简单）

1. 打开 https://nodejs.org/
2. 下载 **LTS 版本**（左边绿色按钮，v22.x.x）
3. 双击 .msi 安装文件，一路「下一步」
4. 装完打开 cmd，输入 `node -v`，显示版本号即成功

### 方式 B：便携版（不想装到系统里）

1. 打开 https://nodejs.org/dist/latest-v22.x.x/
2. 下载 `node-v22.x.x-win-x64.zip`（约 30MB）
3. 解压，把解压出来的文件夹**改名为 `node`**
4. 放到课件文件夹里（和 bat 脚本同级）

bat 脚本会自动优先找便携版，找不到再找系统安装的。

---

## 第二步：部署课件

1. 解压 `xiaoshu-xueqing.zip`
2. 把你的 HTML 课件文件放进同一个文件夹
3. 在课件 HTML 的 `</body>` 前加两行代码：

```html
<script src="xiaoshu-client.js"></script>
<script>
Xiaoshu.config({
  knowledgePoints: ['知识点A', '知识点B'],
  quiz: {
    title: '本课掌握度自评',
    question: '一道适合本课的判断题',
    levels: ['已掌握', '基本理解', '还需复习'],
  },
});
</script>
```

4. 如果课件有交互按钮（提示/答案/判分等），在对应位置加埋点：

```javascript
// 示例：学生点「提示」按钮时
if (typeof Xiaoshu !== 'undefined') Xiaoshu.report('hint', { kp: '知识点A' });

// 示例：学生点「答案」按钮时
if (typeof Xiaoshu !== 'undefined') Xiaoshu.report('answer', { kp: '知识点A' });

// 示例：验证失败时
if (typeof Xiaoshu !== 'undefined') Xiaoshu.report('error', { task: 'ch1', kp: '知识点A' });

// 示例：完成一章时
if (typeof Xiaoshu !== 'undefined') Xiaoshu.report('complete', { task: 'ch1' });
if (typeof Xiaoshu !== 'undefined') Xiaoshu.report('progress', { current: 1, total: 3 });

// 示例：记录课件特定数值（如最终计算结果）
if (typeof Xiaoshu !== 'undefined') Xiaoshu.report('custom', { key: 'final_value', value: 680 });
```

5. 保存 HTML 文件

---

## 第三步：启动课堂服务

### Windows

双击 `启动局域网课堂.bat`

- 首次运行 Windows 防火墙弹窗 → 点「**专用网络**」→ 允许
- 浏览器自动打开教师端看板
- 看板顶部显示学生端地址（如 `http://192.168.1.100:8080/`）

### Linux / Mac

```bash
chmod +x start-classroom.sh
./start-classroom.sh
```

---

## 第四步：学生入班

1. 学生手机/平板连**同一 Wi-Fi**
2. 浏览器打开教师端看板顶部显示的学生端地址
3. 输入姓名，点「进入课堂」
4. 课件正常显示，底部出现三档自评按钮
5. 正常操作课件，数据每 3 秒自动上报，学生无感知

---

## 第五步：下课保存

1. 教师端看板点「**导出 CSV**」→ 浏览器下载 CSV 文件
2. 或点「**清堂重置**」→ 清空数据，准备下一班
3. 关闭 bat 窗口（或 Ctrl+C）→ 服务停止

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 学生端连不上 | 检查防火墙是否允许专用网络；确认师生在同一 Wi-Fi 网段 |
| 端口被占用 | bat 自动顺延到 8081/8082，看板顶部会显示实际地址 |
| 看板显示「等待学生接入」 | 学生还没打开课件，或学生端用的是 file:// 协议（必须用 http://） |
| 换了一台教室电脑 | 把整个文件夹拷过去，Node.js 也要装（或带便携版 node 文件夹） |
| 课件里视频/图片加载不出来 | 素材文件和 HTML 在同一目录，拷的时候别漏 |
